= Solution Pattern: Unified Workload Migration to OpenShift Virtualization
:page-layout: home
:sectnums:
:sectlinks:
:doctype: book

Move your virtual machines and your containers onto a single platform. This solution pattern shows how to migrate existing virtualized workloads to Red Hat OpenShift Virtualization (powered by KubeVirt), unify networking and storage under Kubernetes, and operate VMs with the same tools, pipelines and observability as the rest of your cloud-native estate.

[#use-cases]
== Use cases

Common use cases that can be addressed with this architecture are:

- Migrating VMs away from a legacy hypervisor (for example, VMware vSphere) ahead of a license renewal or data center exit
- Consolidating VM and container platforms into one operational model, one team and one set of tools
- Giving existing VM workloads GitOps, CI/CD and Kubernetes-native networking and storage without re-platforming the application itself
- Building a landing zone for incremental modernization: run the VM on OpenShift today, containerize service by service tomorrow
