= Workshop

A hands-on, five-lab workshop that builds the landing zone from scratch and finishes with a fully functional migrated-style VM. It was presented at Texas Linux Fest 2026.

Participants learn: Linux and OpenShift foundations for virtualization admins, VM networking with Multus and storage with CDI, creating and operating KubeVirt virtual machines, and the day-2 operations every platform team needs (live migration, snapshots, monitoring).

The full workshop site (slides, labs in English and Spanish, and the capstone manifest) is published at https://psehgaft.github.io/txlf2026/ and its sources live in the workshop repository.

== Installing the workshop environment
=== Before getting started

* OpenShift 4.x cluster with OpenShift Virtualization enabled
* `oc` CLI and `virtctl` plugin installed locally
* A default storage class for VM disks; Multus available for secondary networks

=== Installing the environment

Install the OpenShift Virtualization operator from OperatorHub, create the `HyperConverged` instance, and verify the `virt-api` pods are running. Each lab then builds on the previous one inside a dedicated namespace per participant.

[#deliver_wksp]
== Delivering the workshop

. Provision one namespace per participant (or per team) with the workshop's lab manifests.
. Guide participants through Labs 1–3 (foundations, networking and storage, KubeVirt).
. Run Lab 4 as the capstone: every participant deploys a functional VM from the provided manifest.
. Close with Lab 5 (operations): live migration, backup and observability exercises.
