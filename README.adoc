= Solution Pattern: Unified Workload Migration to OpenShift Virtualization

Migrate virtual machines from a legacy hypervisor to Red Hat OpenShift Virtualization (KubeVirt) and operate them next to your containers — one platform, one toolchain.

This repository follows the https://www.solutionpatterns.io[Red Hat Solution Patterns] format and starts from the official `solution-pattern-website-template`.

== Structure

* `documentation/` — Antora content (Home, Architecture, Demo, Workshop)
* `site.yml` / `dev-site.yml` — Antora playbooks for production and local preview

== Build and preview locally

Prerequisites: Git, Node.js 12+ and the Gulp CLI.

[source,shell script]
----
npm install
npx gulp
----

The preview is served at http://localhost:3000.
